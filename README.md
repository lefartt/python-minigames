# Python Mini Games 🎮

A collection of quick and simple Python mini games created while learning Python programming.

The project is organized into levels, with each level gradually increasing in difficulty and introducing new Python concepts.

## Level 1 — Python Basics

Level 1 focuses on the fundamentals of Python:

* Variables
* User input
* Conditional statements
* Loops
* Functions
* Random number generation
* Basic error handling

### Games

1. **Number Guessing** — Guess a randomly generated number between 1 and 100.
2. **Coin Flip** — Guess whether the coin lands on heads or tails.
3. **Dice Roller** — Roll one or multiple dice and calculate the total.

## How to Run

Make sure Python 3 is installed.

From the project directory, run any game using:

```bash
python level-1/number_guess.py
```

```bash
python level-1/coin_flip.py
```

```bash
python level-1/dice_roller.py
```
